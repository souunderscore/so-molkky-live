# so-molkky-live

iPhoneのブラウザからYouTubeライブの予約をまとめて作成・管理するアプリです。

https://souunderscore.github.io/so-molkky-live/

## 予約作成

1. **入力**：時刻の次の行に完成したタイトルを入力します。手入力・コピペ共通で1〜50件に対応し、試合の間の空行は任意です。タイトル形式の制約はありません。
2. **配信設定**：全試合共通の日付（日本時間）・公開設定・説明文・サムネイルを指定します。
3. **確認**：時刻・タイトルを修正し、必要な試合だけ日付・公開設定・説明文・サムネイルを個別指定できます。「共通設定に戻す」で個別指定を解除できます。最終確認後にYouTubeへ登録します。

登録結果から予約管理へ移動できます。部分失敗は失敗分のみ再試行し、サムネイルだけ失敗した場合は予約管理から差し替えてください。登録結果不明時の再作成防止、同一ブラウザ内の複数タブ対策は継続しています。登録済み・登録失敗の入力内容は固定し、再試行での誤った再作成を防ぎます。別の予定を作る場合は結果画面の「新しい予約を作る」を使用します。

## 予約管理

- 状態（予約済み／配信中／終了済み／すべて）、開始日時の並び順、タイトル検索。初期表示は予約済み・早い順です。
- 予約を開いて編集・削除。待機中の予約のみ変更・削除できます。
- チェックした予約の一括削除。対象一覧を確認して実行します。検索・状態・並び順を変えると選択は解除されます。
- 別の予約を開く、画面を切り替える、検索・並び順を変更する際、未保存の編集があれば破棄を確認します。

## 保存とGoogle接続

画面上部の「設定」にGoogle連携、共通設定テンプレート、データ引き継ぎをまとめています。
下書きはボタンを押したときだけ保存し、未保存変更を表示します。旧版の下書き・書き出しファイルも読み込めます。画像は保存・書き出し対象外なので、再選択してください。下書き・テンプレートはこのブラウザだけの保存で、端末間の自動同期はありません。旧テンプレートのデータは保持し、新画面では公開設定・説明文を適用します。

認証トークンはメモリだけに保持します。再読み込み・期限切れ時はGoogleに再接続してください。操作先チャンネルを表示します。

[Google連携・公開・データ移行・実機確認手順](docs/pages-migration.md)

## 開発とテスト

Node.js 24以上を使用します。

```sh
npm ci
npm test
npm run build:pages
```

- `pages/index.html`・`pages/app.css`・`pages/ui.js`：ブラウザ版の画面。
- `pages/client.js`：Google認証、YouTube API、端末内保存、重複防止、バックアップ検証。
- `scripts/build-pages.cjs`：公開用の`dist/`を生成します。
- `tests/pages.cjs`：認証・API・エラー復旧・保存・3ステップ・個別設定・編集保護・検索・一括削除のテスト。
- `Index.html`・`Code.gs`：従来のGAS版。ブラウザ版とは画面を分離して維持しています。
- `tests/smoke.cjs`：GAS版の既存テスト。

自動テストはGoogle・YouTubeと実通信せず、実際の予約を作成・変更・削除しません。実アカウント、iPhone Safari、PRISM連携は実機確認が必要です。

mainへの更新で、テスト後にGitHub ActionsからPagesを公開します。GASへの自動同期・デプロイはありません。clasp 3.4.1、jsdom 27.0.1は開発依存として固定しています。
